# Rider-Pi v0.5.3 — one post-splash after IPv4

Historical tag v0.5.3 points to
[dc7f87521d2d0b80bc00ea30bd19cf937ca4eddf](https://github.com/mpieniak01/Rider-Pi/commit/dc7f87521d2d0b80bc00ea30bd19cf937ca4eddf)
(2025-09-07).

- Post-splash draws once, after /healthz is ready and IPv4 is available.
- SPLASH_WAIT_IP_S defaults to 60 s; IP discovery uses routing/hostname data.
- scripts/sys_splash-info.py became the single entry point, replacing duplicate
  shell scripts. Diagnostic data/splash_trace.log records discovery/backend.
- Boot splash duration became 3 s.

These notes describe that release. Current boot ownership, display rotation,
unit handling and recovery are defined by [LCD documentation](../apps/face-lcd.md)
and [deployment](../DEPLOYMENT.md); historical restart recipes are not the
current upgrade procedure.
