Dynamika programowa

Wartości początkowe formularza to ustawienia programowe, nie pomiary robota. Pułapy uruchomionego wykonawcy: unknown.

Watchdog i granice bezpieczeństwa nie są edytowane w tym formularzu.

Zmierzona jazda — signed command level → m/s

Zmierzony skręt — signed command level → rad/s

Średnia dystans/czas z całej próby obejmuje rampę. Nie jest automatycznie prędkością ustaloną ani wpisem tabeli. Wpisz tylko wartości rzeczywiście zmierzone dla konkretnego signed command level.

Dynamika fizyczna i ograniczenia pomiarów

Nieznane wartości pozostaw puste. Wpisz zmierzoną wartość z jednostką lub notatkę z dowodami. Te obserwacje to notatki operatora, nie aktywne blokady baterii lub przechyłu; nie odblokowują autonomii.

Suwaki prędkości określają następną ręczną próbę. Zmiana reakcji wymaga zapisania i zastosowania. Zapis nie uruchamia ruchu.

Diagnostyka, odometria i HOME

Profil odczytany przez moduły

unknown

Odpowiedź 202 to oczekiwanie. Aktywny profil wymaga świeżego potwierdzenia tego samego skrótu przez motion i odometry. Brak lub stary ACK pozostaje niepotwierdzony.

Rzeczywiste odczyty wykonawcy

Poziomy poleceń pochodzą wyłącznie z zaakceptowanego zapisu motion-executor. Stare kroki są historią, nie dowodem bieżącego ruchu. Każdy kanał IMU i baterii ma własny czas pomiaru; publikacja statusu go nie odnawia.

IMU pokazuje surowe wartości SDK — jednostki nie są zgadywane. Bateria jest przeliczana z poprawnego ułamka 0–1 na %. Przyjęcie zapisu SDK i świeże czujniki nie potwierdzają wykonania fizycznego.

Obserwacje prób — wpisy operatora

Udane i nieudane próby są zapisem dowodów. Dodanie rekordu nie wysyła ruchu ani nie potwierdza jego zakończenia.
