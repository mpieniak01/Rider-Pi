Rzeczywiste odczyty wykonawcy

Kroki SDK pochodzą wyłącznie z zaakceptowanego zapisu motion-executor. Stare kroki są historią, nie dowodem bieżącego ruchu. Każdy kanał IMU i baterii ma własny czas pomiaru; publikacja statusu go nie odnawia.

IMU pokazuje surowe wartości SDK — jednostki nie są zgadywane. Bateria jest przeliczana z poprawnego ułamka 0–1 na %. Przyjęcie zapisu SDK i świeże czujniki nie potwierdzają wykonania fizycznego.

Dynamika programowa

Wartości początkowe formularza to ustawienia programowe, nie pomiary robota. Pułapy uruchomionego wykonawcy: unknown.

Watchdog i granice bezpieczeństwa nie są edytowane w tym formularzu.

Zmierzona jazda — signed SDK step → m/s

Zmierzony skręt — signed SDK step → rad/s

Średnia dystans/czas z całej próby obejmuje rampę. Nie jest automatycznie prędkością ustaloną ani wpisem tabeli. Wpisz tylko wartości rzeczywiście zmierzone dla konkretnego signed SDK step.

Dynamika fizyczna i ograniczenia pomiarów

Nieznane wartości pozostaw puste. Wpisz zmierzoną wartość z jednostką lub notatkę z dowodami. Te obserwacje to notatki operatora, nie aktywne blokady baterii lub przechyłu; nie odblokowują autonomii.

Obserwacje prób — wpisy operatora

Udane i nieudane próby są zapisem dowodów. Dodanie rekordu nie wysyła ruchu ani nie potwierdza jego zakończenia.

Jawnie ustaw zmierzone odniesienie — bez ruchu

Po aktywacji profil kasuje stare odniesienie. Jawnie użyj STOP, sprawdź zatrzymanie i pozycję fizycznie, następnie potwierdź odniesienie. Ten formularz nie wysyła STOP ani ARM. HOME nie jest domyślnym (0,0).

Pojedynczy ręczny impuls

Osobna próba po jawnym ARM powyżej. Przygotuj przestrzeń i kabel, obserwuj robot i użyj STOP. Automatyczne powtarzanie, sekwencje i pomiar z samego ACK są wyłączone.
